# Part C — Wheel Rebuild: Root Cause, Design and Research

## Observed root cause in the current Part B source

The original `spinWheel()` independently chose a random prompt and independently rotated the disc by a random angle. There were no labelled sectors attached to the original disc, so a viewer could not tell which prompt the pointer had selected. The four wheel types also reused a common spin handler while the CSS backgrounds did not present a consistent eight-sector layout.

## Part C fix

- Four wheels—Boyfriend/Land, Dildo, Butt Plug, and Dirty/Wild—now use eight equally sized, visible sectors.
- A fixed pointer sits above the rotating disc; the center button stays stationary.
- The selected sector index determines both the final rotation and the result text. The result is not generated by a second independent random choice.
- The labels stay upright during rotation by counter-rotating them relative to the disc.
- Wheel controls lock while the spin is running; Reset cancels the pending timeout and returns the disc to its initial state.
- Range wheels keep the existing selectors. Their results combine the selected demo range with a clearly labelled safety/communication prompt; ranges are not size recommendations.
- Dirty/Wild sector labels and prompt copy update when the category changes.
- “Phir se ghumao” uses the same improved selection logic. Existing demo add-to-bag behavior is retained for Dildo, Butt Plug, and Dirty/Wild results (no real checkout/discount is implied).
- `prefers-reduced-motion` is respected. Results remain inside the existing live region, and all controls are buttons/selects operable by keyboard.

## Research sources

1. W3C WAI, [Carousel Tutorial](https://www.w3.org/WAI/tutorials/carousels/): meaningful controls, keyboard operation, clear change announcements, and user control over motion.
2. W3C WAI, [Carousel Functionality](https://www.w3.org/WAI/tutorials/carousels/functionality/): use semantic buttons and communicate the selected item through a live region.
3. W3C WAI, [Animation from Interactions (WCAG 2.2)](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html): allow users to reduce or disable nonessential interaction animation.
4. Planned Parenthood, [Sex Toys](https://www.plannedparenthood.org/learn/sex-pleasure-and-sexual-dysfunction/sex-and-pleasure/sex-toys): choose toys intended for the intended use; review dimensions/material/care instructions; anal-use toys should have a flared base or another safe retrieval stop; use suitable lubricant and clean toys as directed.

## Why the wheel is a prompt tool—not a size test

An image cannot establish a person's penis size, toy dimensions or sexual preferences. Range selectors in the product wheels are labelled illustrative/demo ranges, not medical categories or personal recommendations. The result is a fictional conversation/safety prompt, not an order or obligation. Skip is always allowed.

## Verification limits

External raw-GitHub image requests are blocked during those tests so wheel behavior is deterministic; live-host image availability and physical Android interaction remain NOT TESTED until the user uploads and runs `part-c-diagnostics.html`.
